# Путь Кольца — 2D Unity-прототип

Небольшая неофициальная фан-игра по мотивам «Властелина колец». Три последовательно открывающихся уровня: Шир, Мория и Мордор. Двенадцать выбираемых героев, орки, урук-хай, тролль, назгул и финальный противник. Есть препятствия, пропасти, кольца для сбора, здоровье, атака, прыжок и экранные кнопки для Android.

## Открыть в Unity

1. Откройте эту папку через Unity Hub в Unity 2022.3 LTS или более новой совместимой версии. Для сборки APK должны быть установлены модули **Android Build Support**, **Android SDK & NDK Tools** и **OpenJDK**.
2. После импорта откройте меню **Путь Кольца → Создать игровую сцену**. Сцена сохранится в `Assets/Scenes/Game.unity` и откроется автоматически.
3. Нажмите Play. На компьютере: `A/D` или стрелки — движение, `W`/`↑` — прыжок, `Space`/`J` — атака, `Esc` — пауза. На Android используются кнопки на экране.
4. Для APK выберите **Путь Кольца → Собрать Android APK**. Файл появится в `Builds/PutKoltsa.apk`.

Автоматическая сборка через GitHub Actions уже настроена. Подробности: `Docs/BUILDING_ANDROID.md`.

Для пакетной сборки:

```bash
Unity -batchmode -quit -projectPath /absolute/path/to/lotr-2d-unity -buildTarget Android -executeMethod MiddleEarthBuild.BuildAndroid -logFile /absolute/path/to/build.log
```
